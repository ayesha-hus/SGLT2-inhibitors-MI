# SGLT2-inhibitors-MI
Pipeline to investigate the effect of SGLT2 inhibitor use within cohort

### This project was built to run efficiently in R. Data needs to be loaded to local prior to project commencement. 

### There are 3 aims for this project

#### Aim 1:  Is participant adherence to SGLT2 inhibitors associated with any baseline demographic or clinical characteristics- sex, age and body mass index (BMI)?

#### Aim 2:  Estimate the association between treatment allocation (SGLT2 inhibitor plus usual care vs usual care) and time to first secondary MI over 5 years, and assess whether the association differs between early (0-1.5 years) and later (1.5-5 years) follow-up.

#### Aim 3: What is the association between treatment allocation and changes to SBP at the interim assessment (~12 months)?

The pipeline follows the order of aims
