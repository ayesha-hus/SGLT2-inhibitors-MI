# SGLT2-inhibitors-MI
Pipeline to investigate the effect of SGLT2 inhibitor use within cohort

### This project was based on synthetic data and is pipelined to run efficiently in R. Data needs to be loaded to local prior to project commencement. 

## Full list of ibraries required for this project

- readr
- tidyverse
- tableone
- car
- survminer
- survival
- dplyr
